Supabase Customers Table

One-click SQL script for logged-in users database

Thaarai Tex automatically captures past and new customer profiles from your orders and storefront logins. To enable direct real-time customer storage in Supabase, run this script once in your Supabase SQL Editor: 

-- 1. Create customers table
CREATE TABLE IF NOT EXISTS public.customers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  customer_id TEXT UNIQUE,
  name TEXT NOT NULL,
  phone TEXT UNIQUE NOT NULL,
  email TEXT,
  address JSONB DEFAULT '{}'::jsonb,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT now(),
  last_active TIMESTAMPTZ DEFAULT now()
);

-- 2. Create coupons table
CREATE TABLE IF NOT EXISTS public.coupons (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code TEXT UNIQUE NOT NULL,
  percent NUMERIC NOT NULL DEFAULT 10,
  min_total NUMERIC NOT NULL DEFAULT 0,
  active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 3. Enable Row Level Security (RLS)
ALTER TABLE public.customers ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.coupons ENABLE ROW LEVEL SECURITY;

-- 4. Allow Public Storefront & Admin Access
DROP POLICY IF EXISTS "Public access to customers" ON public.customers;
CREATE POLICY "Public access to customers" ON public.customers FOR ALL USING (true) WITH CHECK (true);
DROP POLICY IF EXISTS "Public access to coupons" ON public.coupons;
CREATE POLICY "Public access to coupons" ON public.coupons FOR ALL USING (true) WITH CHECK (true);

✓ Instant Fallback Active

Even before running this script, the admin Customers directory automatically compiles customer records, Customer IDs, phone numbers, and addresses from all store orders!
